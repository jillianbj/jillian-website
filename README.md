## AI Lab: Vibe Coding
In this project, my goal was to apply Information Systems Foundations course material related to Generative AI. I practiced 
the software development process of vibe coding in Antigravity IDE to create a personal website. My personal, academic, and 
professional information is displayed in a hybrid layout to provide both a brief overview of my experience and an opportunity to
view it more in depth. My website can be accessed through this link! https://jillianbj.github.io/jillian-website/

### Reflection
One thing the agent did that I didn't understand at first was create a subfolder for image files used in the website. This
happened when I prompted the agent to format my website in a specific way that included pictures. I had only worked in one flat
level folder for a repository before, and after I asked the agent, I learned that subfolders aren't required but are a 
recommended project structure that increase organization. This led me to include another subfolder for my project files.
