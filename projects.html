ETF Performance Replication

Domain: Financial Modeling and Analytics Course • Honors Project

Python yfinance matplotlib pandas

A Python program that replicates the performance of a specific Exchange Traded Fund (ETF) using its documentation and data from Yahoo Finance.

  • Jupiter Notebook formatted program written in Google Colab.
  • Generates indicator triggers, determines index exposure, and assigns etf weights.
  • Calculates ETF returns and cumulative performance.
  • Compares the replicated ETF performance to the actual ETF performance and analyzes using data visualizations.
