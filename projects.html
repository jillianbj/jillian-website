Featured Projects

1. KubeScope – Kubernetes Cluster Resource Auditor

A fast, lightweight command-line tool written in Go that inspects Kubernetes clusters for misconfigured resource requests and limits, unhealthy pod workloads, orphaned persistent volumes, and stale deployments.

Key Features:

  • Interactive and JSON-formatted reports analyzing cluster-wide resource efficiency.
  • Out-of-the-box recommendations for right-sizing pod CPU and memory requests.
  • Pluggable rules engine built with Go client-go and Cobra CLI framework.
  • Easily integrates into CI/CD pipelines via GitHub Actions.

Technologies: Go, client-go, Cobra, Kubernetes API, GitHub Actions, Docker
Links: Source Code | Documentation

2. MiniKV – Embedded LSM-Tree Key-Value Store

An educational Log-Structured Merge-tree (LSM-tree) storage engine implemented in Rust to study Write-Ahead Log (WAL) crash recovery, SSTable compaction strategies, and Bloom filter optimizations.

Key Features:

  • MemTable implementation backed by a lock-free SkipList for concurrent in-memory writes.
  • Write-Ahead Logging with checksum verification ensuring durability against unexpected power loss.
  • Size-tiered compaction strategy to bound read amplification and reclaim disk space.
  • Block-level Bloom filters reducing unnecessary disk reads for non-existent keys.

Technologies: Rust, Concurrency, File I/O, Data Structures, Benchmarking
Links: Source Code | Technical Writeup

3. TraceFlow – OpenTelemetry Pipeline Simulator

Synthetic distributed trace generator and benchmarking suite designed to validate OpenTelemetry collectors, agents, and backend storage engines under extreme traffic spikes and bursty network conditions.

Key Features:

  • Simulates complex microservice topologies with customizable call depths and error injection rates.
  • Exports spans in OTLP/gRPC and OTLP/HTTP protocols with configurable sampling rates.
  • Provides real-time throughput and latency metrics comparing collector resource utilization.
  • Fully packaged with Docker Compose for local development and integration tests.

Technologies: Python, Asyncio, OpenTelemetry SDK, gRPC, Docker, Prometheus
Links: Source Code | Documentation

4. NetPulse – eBPF Network Latency & Packet Monitor

A low-overhead Linux kernel observability tool that leverages eBPF (extended Berkeley Packet Filter) to measure TCP connection round-trip times and identify packet drops without application code modification.

Key Features:

  • Attaches kernel probes to TCP state machine transitions with sub-microsecond overhead.
  • Exports Prometheus metrics for TCP retransmissions, SYN backlog queue saturation, and socket latency.
  • Lightweight Go userspace daemon for metric aggregation and filtering.

Technologies: Go, C, eBPF, Linux Kernel, Prometheus, Grafana
Links: Source Code | Architecture Spec
